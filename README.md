# دستیار هوش مصنوعی - BotWin

یک فرانت‌اند مدرن برای ربات دستیار ویندوز با استفاده از HTML، CSS و JavaScript.

## 📦 فایل‌های موجود

- `ai_assistant_9router-3.py` - برنامه پایتون اصلی (Backend)
- `index.html` - فرانت‌اند وب مدرن (2D Interface)

## 🚀 نصب و اجرا

### روش ۱: اجرا مستقیم (بدون سرور web)

1. فایل `index.html` را باز کنید:
   - روی فایل راست‑کلیک کنید → "Open with" → مرورگر دلخواه (Chrome/Firefox/Edge)
2. در صفحه باز شده روی "تنظیمات" کلیک کنید
3. اطلاعات اتصال را وارد کنید:
   - **Base URL**: آدرس API شما (مثلاً `http://localhost:20128/v1` برای 9Router)
   - **API Key**: کلید اختصاصی (اختیاری)
   - **مدل**: نام مدل هوش مصنوعی (مثلاً `gpt-4o`)
4. روی "ذخیره" و سپس "دریافت مدل‌ها" کلیک کنید (اختیاری)
5. در باکس پشت‌ب备注 رو پیام خود را بنویسید و ارسال کنید

### روش ۲: اجرا با وب‌سرور (ساده‌تر برای تاریخچه و بهینه‌تر)

#### تنظیم WebSocket Backend (اختیاری)
در حال حاضر فرانت‌اند به آدرس `http://localhost:9222` اتصال دارد برای اجرای ابزارها. این می‌تواند توسط برنامه پایتون `ai_assistant_9router-3.py` پوشينده شود (در آینده).

#### اجرای وب‌سرور HTTP
از لحظه‌ای Φ، می‌توانید از وب‌سرور خیلی سبک (وادر) استفاده کنید:

```bash
pip install -U uv
uv run -- http-server --port 8000
```

سپس به آدرس زیر بروید: `http://localhost:8000/index.html`

یا با HTTP Server پیش‌فرض Python:

```bash
python -m http.server 8000
# و سپس: http://localhost:8000/index.html
```

## ⚙️ تنظیمات

- تنظیمات در مرورگر شما ذخیره می‌شوند (`localStorage`)
- برای پاک کردن تاریخچه روی "پاک کردن چت" کلیک کنید

## 🎨 ویژگی‌های فرانت‌اند

- طراحی تیره و مدرن
- پشتیبانی کامل از زبان فارسی (RTL)
- کارت‌های چت با طرح‌های تمیز
- وضعیت سیستم (متصل/غیرمتصل) و نام مدل
- مدل‌بندی انواع پیام (کاربر، دستیار، ابزار، خطا)
- لودینگ دارک
- اسکرول‌بار سفارشی‌سازی‌شده
- فونت عمومی (`Tahoma` → `Segoe UI`)

## 🔌 ابزارهای پشتیبانی‌شده

از طریق API/Message فرانت‌اند فعلاً به ابزارها متصل نیست و بلافاصله به هوش مصنوعی ارسال می‌شود. برای اجرای ابزارها به یک WebSocket(local) بین نقش فرانت‌اند و Backend نیاز داریم (در نسخه نهایی).

### ابزارها (Function Calling):
- `open_app` - باز کردن برنامه‌های مجاز (notepad, calc, paint, explorer, cmd)
- `open_url` - باز کردن وب‌سایت
- `save_note` - ذخیره یادداشت
- `list_notes` - لیست یادداشت‌ها
- `read_note` - خواندن یادداشت
- `current_time` - ساعت سیستم

## 📝 مثال استفاده

پیام‌ها از جملات ساده قابل فهم هستند:
- "اکنون ساعت چقدر است؟"
- "یک یادداشت به نام معرفی‌نامه بساز و بنویس:"
- "نوت‌پد را باز کن"
- "آدرس اینترنت را از اینترنت باز کن"
- "لیست یادداشت‌ها"

پخش (Streaming) زمانی فعال است که سرور آن را پشتیبانی کند.

## 🔧 توسعه و شخصی‌سازی

- برای تغییر تم، ویرایش `:root` در بخش `style` در `index.html`
- برای اضافه کردن ابزارهای جدید، ویژگی‌های `executeTool` در اسکریپت را تغییر دهید
- برای تبدیل به ابزار کامل، به یک چینش Gateway/Bridge نیاز دارید

## 📌 نکته مهم

نسخه فعلی فرانت‌اند فقط در مرورگر کار می‌کند. برای اجرای ابزارها و بهینه‌تر شدن بیشتر به یک بک‌اند (Backend) که آدرس `http://localhost:9222` را پخش کند و به سرویس‌های ویندوزیصل توی فرانت‌اند راه‌اندازی کند، نیاز داریم. نسخه پایتون فعلی ابزارها را در سمت سرور اجرا می‌کند.
